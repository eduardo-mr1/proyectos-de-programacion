# Complejidad algoritmica

La notacion O grande describe como crece el costo de un algoritmo cuando crece
la entrada. Un recorrido lineal es O de n, una busqueda binaria sobre datos
ordenados es O de log n, y el acceso a una tabla hash es O de uno en el caso
promedio.

Elegir la estructura de datos correcta suele importar mas que optimizar el
codigo linea por linea. Cambiar un arreglo por un mapa puede convertir un
algoritmo cuadratico en uno lineal, y esa diferencia se vuelve enorme cuando el
volumen de datos aumenta.
