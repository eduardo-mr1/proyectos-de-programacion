# Pruebas automatizadas

Una suite de pruebas automatizadas detecta regresiones antes de que lleguen a
produccion. Las pruebas unitarias verifican piezas aisladas, las de integracion
verifican que esas piezas funcionen juntas, y las de extremo a extremo recorren
el flujo completo como lo haria un usuario.

El valor no esta en la cantidad de pruebas sino en cuales fallan cuando algo se
rompe de verdad. Una prueba que nunca falla no esta protegiendo nada.
