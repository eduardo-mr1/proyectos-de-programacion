# Bases de datos relacionales

Una base de datos relacional organiza la informacion en tablas con filas y
columnas, y define relaciones entre ellas mediante llaves foraneas. El lenguaje
SQL permite consultar, insertar, actualizar y eliminar esos datos.

Los indices aceleran las consultas evitando recorrer la tabla completa, con el
costo de ocupar espacio y hacer las escrituras un poco mas lentas. La idea es la
misma que en un indice invertido de texto: pagar en escritura para ahorrar
muchisimo en lectura.
